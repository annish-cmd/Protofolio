# To test admin panel

**Requirements**

_this is to test admin panel locally_

- docker desktop to run supabase
- supabase cli
- nvm-windows for npm in windows or relevant on linux

---

_commands_

- install npm
  `nvm install lts`

- install supabase cli -> inside admin dir
  `npm install supabase --save-dev`

- create supabase project -> inside admin dir
  `npx supabase init`

- start supabase cli -> inside admin dir
  `npx supabase start`

- check supabase status -> inside admin dir
  `npx supabase status`

- reset supabase db -> inside admin dir
  `npx supabase db reset`
